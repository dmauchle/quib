# Review Documentation Skill

## Overview

This skill reviews the documentation (user guide in /docs/UserGuide) of this project and looks for inconsistencies.

## Instructions

Go through all .md files in `/docs/UserGuide/` and perform the following checks:

### Check for typos

1. Check for typos, spelling mistakes, and grammatical errors in the documentation.
2. Suggest corrections for the typos.

### Check markdown links

1. Check all markdown links in the documentation for broken links or incorrect references.
2. Let me know if you find any issues, and suggest corrections.
3. Apply the corrections if you are confident in your suggestions. Otherwise, ask for clarification before making changes.

### Check code examples

1. Check the code examples for code that would not compile against the actual code.
2. Let me know if you find any issues, and suggest corrections.
3. Apply the corrections to the documentation if you are confident in your suggestions. Otherwise, ask for clarification before making changes.


## Do's and Don'ts

### Don'ts

- Don't write a summary file.
